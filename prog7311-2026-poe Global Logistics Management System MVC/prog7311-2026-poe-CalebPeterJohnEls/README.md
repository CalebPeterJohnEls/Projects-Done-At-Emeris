## 2.	CHANGE FROM ABSTRACT FACTORY TO STRATEGY
I change the design pattern of my Exchange Rate Method from Abstract Factory to Strategy. 
This was since I found simpler to implement than the previous one.
The Strategy pattern encourages composition over inheritance, permits 
adding new behaviours without altering old code, allows you to swap algorithms at runtime, 
and keeps algorithm details apart from usage. (Refactoring Guru, 2024a)
