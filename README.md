## 🚀 About This Repository

This repo serves as a portfolio of academic work completed during my studies, demonstrating growth across:
- **Front-end development** (HTML, CSS, JavaScript)
- **Mobile development** (Kotlin, Firebase, React Native)
- **Back-end & full-stack development** (C#, ASP.NET MVC, SQL)
- **Cloud & DevOps** (Azure, DigitalOcean, Docker)
- **Design** (Figma wireframes)

Each folder contains the source code for a specific module/project, along with any relevant documentation. Build artifacts and IDE-generated files (e.g. `bin/`, `obj/`, `.vs/`) are excluded from tracking via `.gitignore`.
