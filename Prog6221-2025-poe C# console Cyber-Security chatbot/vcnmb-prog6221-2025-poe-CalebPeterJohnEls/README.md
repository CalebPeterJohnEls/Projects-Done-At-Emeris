## How to open file 🔓
1. Copy Github link.
2. Go to Visual Studio.
3. Select Clone a repository.
4. Paste Github link in repository location.
5. Click Clone. And your file will be downloaded.
6. Once open, make sure you select the program file and that you are in the file looking at the code.
7. Go to the top and click run. It has a play symbol. ▶️
8. Wait for the console to pop up.
9. Start typing and you can enjoy the Cyber-security bot and learn about cyber-security.
